# 福利彩票历史数据

## 双色球（SSQ）

### 基础信息
- **红球：** 01-33，选6个
- **蓝球：** 01-16，选1个
- **头奖概率：** 1/17,721,088（约1/1772万）

### 数据文件
- `ssq_history.csv` - 双色球历史开奖数据（3326条，2003001~20260042）

### 数据字段
| 字段 | 说明 |
|------|------|
| 期号 | 开奖期次 |
| 红球1-6 | 红球号码（由小到大） |
| 蓝球 | 蓝球号码 |
| 开奖日期 | YYYY-MM-DD |
| 销售额 | 当期销售额（元） |
| 头奖注数 | 一等奖中奖注数 |
| 头奖奖金 | 单注奖金（元） |

### 数据来源
- 中彩网（www.zhcw.com）
- 中国福利彩票发行管理中心

### 更新频率
每周二、四、日开奖后次日更新
