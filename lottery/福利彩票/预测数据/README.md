## 预测说明

### "预测"的两层含义

1. **统计分析（客观）：** 基于历史数据的统计分布分析
   - 如：红球01-11区间历史出现频率统计
   - 如：奇偶比例分布
   - 如：AC值分布、和值分布

2. **娱乐推荐（主观）：** 应用户要求生成的随机号码
   - 仅供娱乐
   - 绝不等同于"预测"

### 文件说明

| 文件 | 内容 |
|------|------|
| `statistics_analysis.md` | 统计分析报告 |
| `entertainment_picks.md` | 娱乐选号推荐（如有） |

### 核心原则

- ❌ 绝不声称"本期必开X号"
- ❌ 绝不包装成"算法预测"
- ✅ 仅呈现可验证的历史统计数据
- ✅ 每次推荐明确标注"娱乐性质，概率极低"
