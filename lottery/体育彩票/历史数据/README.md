# 体育彩票历史数据

## 大乐透（Super Lotto）

### 基础信息
- **红球：** 01-35，选5个
- **蓝球：** 01-12，选2个
- **头奖概率：** 1/2,142,784,704（约1/2142万）

### 数据文件
- `ssq_history.csv` - 双色球历史开奖数据
- `dlt_history.csv` - 大乐透历史开奖数据

### 数据字段
| 字段 | 说明 |
|------|------|
| 期号 | 开奖期次 |
| 红球1-5 | 红球号码（由小到大） |
| 蓝球1-2 | 蓝球号码（由小到大） |
| 开奖日期 | YYYY-MM-DD |
| 销售额 | 当期销售额（元） |
| 头奖注数 | 一等奖中奖注数 |
| 头奖奖金 | 单注奖金（元） |

### 数据来源
- 中国体彩网（www.lottery.gov.cn）
- 中彩网（www.zhcw.com）

### 更新频率
每周二、四、日开奖后次日更新
