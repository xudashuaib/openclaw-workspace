## 三、定时任务方案

### 3.1 彩票预测号码生成

| 项目 | 内容 |
|------|------|
| **任务名** | 彩票预测号码生成 |
| **触发时间** | 每周一、三、六 12:30 |
| **Cron表达式** | `30 12 * * 1,3,6` |
| **时区** | Asia/Shanghai |
| **执行内容** | 生成下一期双色球 + 大乐透各6组预测号码 |
| **号码策略** | 每期：热号组×2 + 冷号组×2 + 随机组×2 |

> **时机说明：** 12:30生成，当晚开奖（21:30）。有约9小时窗口让用户查看和决策是否购彩。

### 3.2 双色球开奖结果通知

| 项目 | 内容 |
|------|------|
| **任务名** | 双色球开奖结果通知 |
| **触发时间** | 每周二、四、日 21:25 |
| **Cron表达式** | `25 21 * * 2,4,7` |
| **时区** | Asia/Shanghai |
| **执行内容** | 查询最新双色球开奖结果，与预测号码核对，输出中奖情况 |

> **时机说明：** 21:25触发，21:30开奖。留出5分钟脚本执行+等待开奖时间。

### 3.3 大乐透开奖结果通知

| 项目 | 内容 |
|------|------|
| **任务名** | 大乐透开奖结果通知 |
| **触发时间** | 每周一、三、六 21:35 |
| **Cron表达式** | `35 21 * * 1,3,6` |
| **时区** | Asia/Shanghai |
| **执行内容** | 查询最新大乐透开奖结果，与预测号码核对，输出中奖情况 |

> **时机说明：** 21:35触发，大乐透21:30开奖后约5分钟出结果，略有缓冲。

### 3.4 任务汇总表

| 任务 | Cron | 彩票类型 | 说明 |
|------|------|----------|------|
| 彩票预测号码生成 | `30 12 * * 1,3,6` | 双色球+大乐透 | 开奖日前生成6组号码 |
| 双色球开奖结果通知 | `25 21 * * 2,4,7` | 双色球 | 开奖日21:25核对 |
| 大乐透开奖结果通知 | `35 21 * * 1,3,6` | 大乐透 | 开奖日21:35核对 |

## 四、预测号码生成规则

### 4.1 号码池划分

| 池 | 划分规则 | 说明 |
|---|----------|------|
| 热号池 | 历史出现频率排名前18的号码 | 高频区域 |
| 冷号池 | 历史出现频率排名后18的号码 | 低频区域 |

- 每次从对应池中随机抽取
- 热号池和冷号池互不重叠

### 4.2 每期组数（每种彩票各6组）

| 组 | 类型 | 选号策略 |
|---|------|----------|
| 1-2 | 热号组 | 红球/前区从热号池，篮球/后区从热号池 |
| 3-4 | 冷号组 | 红球/前区从冷号池，篮球/后区从冷号池 |
| 5-6 | 随机组 | 全部随机 |

### 4.3 大乐透追加说明

- 每注大乐透默认追加（2元基本+1元追加=3元/注）
- 奖金规则：追加奖金=基本奖金×0.8

## 五、开奖结果核对规则

### 5.1 双色球奖金

| 奖等 | 条件 | 奖金 |
|------|------|------|
| 一等奖 | 6红+蓝 | 浮动 |
| 二等奖 | 6红 | 浮动 |
| 三等奖 | 5红+蓝 | 固定3000元 |
| 四等奖 | 5红无蓝 或 4红+蓝 | 固定200元 |
| 五等奖 | 4红无蓝 或 3红+蓝 | 固定10元 |
| 六等奖 | 2红+蓝 或 1红+蓝 或 0红+蓝 | 固定5元 |

### 5.2 大乐透奖金（含追加）

| 奖等 | 条件 | 基本奖金 | 追加奖金 |
|------|------|----------|----------|
| 一等奖 | 5前区+2后区 | 浮动 | 浮动×0.8 |
| 二等奖 | 5前区+1后区 | 浮动 | 浮动×0.8 |
| 三等奖 | 5前区 或 4前区+2后区 | 浮动 | 浮动×0.8 |
| 四等奖 | 4前区+1后区 | 5000 | 4000 |
| 五等奖 | 4前区 或 3前区+2后区 | 500 | 400 |
| 六等奖 | 3前区+1后区 或 2前区+2后区 | 200 | 100 |
| 七等奖 | 3前区 或 2前区+1后区 | 100 | 50 |
| 八等奖 | 1前区+2后区 或 0前区+2后区 | 15 | 0 |
| 九等奖 | 1前区+1后区 | 15 | 0 |

## 六、输出格式规范

### 6.1 预测号码输出格式

```
大乐透（{开奖日期} 后开奖）：
  01 02 03 04 05 + 06 07
  ...

双色球（{开奖日期} 后开奖）：
  01 02 03 04 05 06 + 07
  ...
```

> **注意：** 输出仅显示号码，不显示"热号""冷号"等标注，不做伪科学包装。

### 6.2 开奖结果输出格式

```
🎰 彩票开奖结果 {日期}

📊 累计统计 | 双色球 投入X元/中奖Y元 (ROI%) N期 | 大乐透 投入X元/中奖Y元 (ROI%) N期

【双色球】{期号}期 {日期} 开奖: {号码}
预测: {号码} | {奖等}+{金额}元 | ...
本期投入: {金额}元 | 中奖: {金额}元

【大乐透】{期号}期 {日期} 开奖: {号码}
预测: {号码} | {奖等}+{金额}元 | ...
本期投入: {金额}元 | 中奖: {金额}元
```

{
  "ssq": { "total_cost": 0, "total_win": 0, "draws": 0 },

- `total_win`: 累计中奖（元）
